## 正文

又发现一个值得收藏的 UI 设计资源网站！🔥
	
这次分享的是 Blossom Carousel，一个专注于网页轮播交互的组件库。
	
它最吸引我的地方有两个：
	
🎨 1. 高级 UI 交互组件
不是普通的图片轮播，而是提供了很多有设计感的交互效果：
	
- Cover Flow：3D 卡片流动效果
- Flipbook：立体翻页效果
- Stories：故事卡片交互
- Sticky Slides：粘性卡片效果
- 拖拽、滚动吸附等交互效果
	
🤖 2. 支持 AI Skill
这个才是重点！
	
网站提供了专门的 Agent Skills，可以安装到支持 Skills 的 AI 编程工具中。
	
安装命令：
	
npx skills add https://blossom-carousel.com
	
让 AI 更好地理解和使用 Blossom Carousel 组件，辅助搭建网页交互效果。
	
✨ 适合谁收藏？
- UI设计师：寻找高级交互动效灵感
- 前端开发者：快速使用轮播组件
- Vibe Coding 玩家：让 AI 辅助实现高级 UI 效果
	
现在找设计资源，不仅要看组件好不好看，还要看能不能直接融入 AI 工作流。
	
🔗 官网：https://blossom-carousel.com/
	
建议收藏，下次做作品集、产品官网和交互页面时都能用得上！
