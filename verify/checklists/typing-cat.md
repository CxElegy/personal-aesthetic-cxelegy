# 复刻清单：typing-cat（第 2 版）

原作：小红书「有没有能get到的🐱」（艾_），本地 `references/xhs/2026-11-20-有没有能get到的🐱-018db4/`（原视频 43 秒，`video.mp4` 不进 git）。复刻：`demos/typing-cat.html`。
范围内：猫的造型、各个状态和它们之间的过渡、眼睛跟随、打字联动、键帽、键盘高亮、鼠标。
范围外：真正的桌面悬浮窗和全局键盘监听（网页做不到，需要 Tauri 或 Electron，另立项）。
完成 = 所有「必须」项连续两轮复查都通过，并且用户接受剩下的差距。

路线（用户 2026-11-21 定）：朝 6C 方向做，分数越高越好。Rive 编辑器需要人手操作，云端做不了，所以用代码实现同一层级的技术：
同点数轮廓关键形插值（网格变形）+ 两节 IK 前爪 + 角度弹簧尾巴 + 弹簧权重的分层状态机。

## 心动点（第一个必须项）
**一只会「表演」的小黑猫**：身体在姿势之间连续变形（不是切图）；你用鼠标它就伸爪搭着鼠标，你打字它就趴下来两爪交替敲，被摸时眯成两条细线。

## 技术层级和上限
原作：骨骼 + 网格变形 + 状态机（E-03、E-10，derived）。复刻：同一层级，用代码实现（不是 Rive 文件），所以没有手绘的二级变形（脸颊肉、耳朵的柔性），这是剩下的主要差距。
